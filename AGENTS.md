# Project Coconut — personal website

Build a personal engineering website for Arun Rajan, at learnwitharunrajan.com.

## Priorities

- Share original learning, practical experiments, and clear technical writing.
- Keep one website and domain, with sections for writing, projects, experience, education, patents, resume and personal interests.
- Prefer static rendering, accessibility, responsive design, and search-friendly metadata.
- Use GitHub Free and Vercel Hobby. Minimize recurring costs and use free/open-source tooling.
- AWS and Oracle Cloud Infrastructure (OCI) are the primary clouds for future systems projects. Estimate costs before provisioning billable resources.
- Keep credentials, private information, and employer-confidential material out of the public repository.
- Verify builds before deployment. Use factual content and clearly distinguish proposed projects from completed work.
